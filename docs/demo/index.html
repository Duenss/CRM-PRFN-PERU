Cómo funciona

Al enviar una promoción se manda la imagen como mensaje aparte y el texto como respuesta. Si el cliente pide 2 o 3, el bot usa la promoción activa y avisa al número de Ajustes solo si requiere que un asesor cierre la venta.

El número de alertas es global y se configura en Ajustes (no aquí).
